# Contributing

Thanks for helping improve `repo-to-agents`.

## Development Setup

```sh
npm install
npm test
npm run build
```

## Pull Request Guidelines

- Keep changes focused on one behavior or documentation topic.
- Add or update tests for detection, generation, CLI, or writer behavior changes.
- Preserve deterministic output. Do not include timestamps, machine-specific paths, or nondeterministic ordering in generated files.
- Avoid runtime dependencies unless the benefit is clear and documented.
- Update `README.md` and `CHANGELOG.md` when user-facing behavior changes.

## Generated File Policy

Generated instruction files contain this marker:

```md
<!-- Generated by repo-to-agents. Edit source repository patterns, then rerun. -->
```

The CLI may update files with that marker. It will not overwrite unmarked files unless `--force` is used.

## Release Checklist

1. Update `CHANGELOG.md`.
2. Run `npm test`.
3. Run `npm run build`.
4. Publish from a clean working tree.
