# repo-to-agents

`repo-to-agents` is a deterministic TypeScript CLI that inspects a repository and generates practical AI coding-agent instructions. It creates `AGENTS.md` by default and can also generate target-specific guidance for GitHub Copilot, Cursor, and Claude.

The tool is intentionally dependency-light: no runtime dependencies, predictable output, and file writes that avoid overwriting hand-written instructions unless explicitly allowed.

## Features

- Detects common repository signals: `package.json`, package manager lockfiles, `pyproject.toml`, requirements files, `go.mod`, `Cargo.toml`, `Makefile`, Docker files, Compose files, `tsconfig.json`, test configs, GitHub Actions, README content, and common source directories.
- Generates structured instructions with overview, detected stack, commands, architecture map, coding conventions, testing expectations, environment notes, safety boundaries, and contribution workflow.
- Supports multiple instruction targets:
  - `AGENTS.md`
  - `.github/copilot-instructions.md`
  - `.cursor/rules/repository.mdc`
  - `CLAUDE.md`
- Provides `--check` for CI drift detection.
- Refuses to overwrite existing unmarked files unless `--force` is used.

## Installation

```sh
npm install --save-dev github:michaelko/repo-to-agents
```

You can also run it from a local checkout:

```sh
npm install
npm run build
node dist/src/cli.js --help
```

## Usage

Generate `AGENTS.md` to stdout:

```sh
repo-to-agents --stdout
```

Write `AGENTS.md` into the current repository:

```sh
repo-to-agents --write
```

Generate multiple targets:

```sh
repo-to-agents --write --targets agents,copilot,cursor,claude
```

Inspect another repository:

```sh
repo-to-agents ../my-service --stdout
```

Write `AGENTS.md` to a custom path:

```sh
repo-to-agents --write --output docs/AGENTS.generated.md
```

Check generated files in CI:

```sh
repo-to-agents --check --targets agents,copilot
```

Use `--force` only when you intentionally want to replace existing unmarked files:

```sh
repo-to-agents --write --force --targets agents,copilot
```

## CLI Reference

```text
repo-to-agents [repo-path] [options]

Options:
  --write                      Create or update generated instruction files.
  --check                      Exit nonzero when generated files are missing or stale.
  --force                      Allow --write to replace existing unmarked files.
  --stdout                     Print generated output to stdout.
  --targets <list>             Comma-separated targets: agents,copilot,cursor,claude.
  --output <path>              Output path for AGENTS.md when target "agents" is selected.
  --version, -v                Print the CLI version.
  --help, -h                   Show help.
```

If neither `--write` nor `--check` is provided, the CLI prints generated output to stdout.

## Generated Output Sample

```md
# AGENTS.md
<!-- Generated by repo-to-agents. Edit source repository patterns, then rerun. -->

## Overview
This is guidance for AI coding agents working in `example-service`.

## Detected Stack
- Languages: `TypeScript`, `YAML`.
- Frameworks and tools: `ESLint`, `GitHub Actions`, `Vitest`.
- Package manager: npm (package-lock.json).

## Commands
| Purpose | Command | Source |
| --- | --- | --- |
| Install dependencies | `npm install` | package.json |
| Package script: test | `npm test` | package.json scripts.test |

## Safety Boundaries
- Do not overwrite user changes or generated instruction files unless the file contains the repo-to-agents marker or the user explicitly asks.
```

## CI Usage

Add a workflow step after installing dependencies:

```yaml
- run: npx repo-to-agents --check --targets agents,copilot,cursor,claude
```

When generated output changes intentionally, run the write command locally and commit the result:

```sh
repo-to-agents --write --targets agents,copilot,cursor,claude
```
